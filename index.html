The Six / Extra

The Six는 최대 6명이며 모든 숙제를 완료 대상으로 봅니다. Extra는 목표를 선택하고 활성화한 숙제만 완료율에 포함합니다.

체크 초기화

현재 브라우저에 저장된 완료 상태만 초기화합니다.

로스트아크 API

API는 캐릭터 정보만 갱신합니다. 숙제 구성과 The Six/Extra 설정은 유지됩니다.

The Six 자동 할당

Extra는 자동 완료 대상이 아닙니다. 보석·실링·재련 재료·카드·편린·큐브 티켓 같은 목표를 선택하고 필요한 숙제만 활성화합니다.
